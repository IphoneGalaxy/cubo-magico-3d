# Componentes nativos

O projeto já declara `androidx.compose.material3` e Material Icons core/extended. Não é necessário baixar componentes React, Tailwind, HTML ou CSS.

| Necessidade | Base existente |
|---|---|
| Botões e ações | Button, OutlinedButton, IconButton |
| Cartões e superfícies | Card, Surface, RoundedCornerShape |
| Tipografia | Typography em ui/theme/Type.kt |
| Cores e temas | Color.kt e Theme.kt |
| Progresso | LinearProgressIndicator |
| Cubo interativo | InteractiveCube3DView / CubeGLRenderer |
| Guia de notação | NotationGuideModal.kt |

Esta pasta documenta os componentes; não contém um kit executável novo. Integrar assets futuramente usando as estruturas atuais e validar telas pequenas, paisagem, tema claro/escuro, acessibilidade e toque.
